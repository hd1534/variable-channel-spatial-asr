01 / OVERVIEW

Variable-Channel Spatial ASR

가변 마이크 입력을 지원하는 공간 음성인식

마이크 1개부터 4개까지, 하나의 가중치로 전사와 화자와 위치를 함께 추정합니다.

마이크 수가 달라지면 보통 모델을 따로 만듭니다. 이 Challenge는 1~4채널을 단일 가중치로 처리합니다.

출력은 세 가지입니다. 발화 내용, 세션 내 익명 화자 ID, 화자의 방위각과 거리.

위치는 점 하나가 아니라 확률 분포로 제출합니다. 마이크가 적으면 방향을 알 수 없고, 그 사실까지 분포로 표현해야 합니다.

VARIABLE CHANNEL

Single Weight Set

1~4채널을 하나의 가중치로 처리

SPATIAL OUTPUT

Distribution First

방위각·거리 주변분포와 2D 점 추정

REPRODUCIBILITY

Fully Open Eval

평가셋·정답·채점 코드 전체 공개

36AZIMUTH BINS @10°
0.25 sEVALUATION GRID

Task Definition

허용된 관측 범위의 다채널 오디오만 입력받아 전사와 화자와 위치를 동시에 출력합니다.

TRACK 1

Single Stationary Speaker

한 세션에 한 명. 화자 전환이 없어 cpWER과 적응 지연은 정의되지 않습니다.

03 / METHOD

Baseline & Method

베이스라인 두 개는 학습이 필요 없습니다. 제안 모델만 학습합니다.

BASELINE 1

Single Channel + Frozen ASR

활성 채널 중 최저 인덱스 하나만 사용. 방위각은 균일 분포, 거리는 에너지 기반 회귀.

학습 불필요

BASELINE 2

SRP-PHAT + Delay-and-Sum

36개 방향의 조향 응답을 softmax로 분포화. 추정 방향으로 빔포밍한 단일 채널을 같은 Frozen ASR에 입력.

학습 불필요

PROPOSED

TAC + GRU

가변 채널 TAC로 공간 특징을 통합. 동일 GRU 구조에서 청크 간 상태 전달만 켜고 끕니다.

학습 필요 · 12/7 마감

통제 변인

세 시스템에서 ASR과 화자 인코더와 관측 범위를 같게 둡니다. 성능 차이의 원인을 프론트엔드와 시간 상태로 좁히기 위한 조건입니다.

요소상태값
ASR 백엔드FIXEDwav2vec2-base-960h (frozen)
화자 인코더FIXEDECAPA-TDNN (frozen)
관측 범위FIXEDcausal
청크 길이 / hopFIXED1.0 s / 0.25 s
공간 프론트엔드VARIED단일 채널 · SRP-PHAT · TAC
청크 간 상태 전달VARIEDChunk-Reset · Carry-Over
위치 출력 분기만 추가하고 ASR 입력과 추론 경로가 같다면 WER 향상을 주장하지 않습니다. 그 경우는 전사에 공간·화자 정보를 더한 멀티태스크 시스템으로 평가합니다.

재현 절차

1

평가셋 생성

고정 시드로 eval-dev를 만듭니다.

2

베이스라인 추론

predictions.jsonl을 출력합니다.

3

로컬 채점

evaluate.py로 점수를 확인합니다.

# 1) 평가셋 생성 (고정 시드)
python make_eval_dev.py --out data/eval-dev --n-sessions 12 --seed 20261029

# 2) 베이스라인 추론
python -m baselines.single_channel --eval-dir data/eval-dev \
    --out predictions.jsonl --scope causal --track 1

# 3) 로컬 채점
python evaluate.py --pred predictions.jsonl \
    --gt data/eval-dev/ground_truth.jsonl --track 1

evaluate.py는 표준 라이브러리와 numpy만 씁니다. 외부 서버나 유료 계정 없이 같은 점수가 나옵니다.

04 / DATASET

Dataset

LibriSpeech 음성을 4채널 공간 음향으로 합성합니다. 평가셋은 정답까지 전부 공개합니다.

REQUIRED

eval-dev

오디오, 입력 메타데이터, 정답 라벨, 파일 목록 전체 공개. 외부 서버 없이 로컬에서 같은 점수를 재현합니다.

다운로드 ↗

OPTIONAL

오디오와 입력 메타데이터만 공개. 정답은 비공개 보관. 웹 Judge 운영 시에만 필요합니다.

마이크 배열

반경5 – 12 cm
마이크 쌍 최대 간격24 cm
λ/2 에일리어싱 한계≈ 715 Hz
평가 채널 부분집합6개 고정
마이크·음원 높이z = 1.5 m 동일

채널을 빼더라도 원점 (0,0)과 좌표축은 유지합니다. 활성 마이크 중심으로 원점을 다시 잡으면 채널 수 변화와 좌표계 변화가 섞입니다.

누출 방지 규칙

  • 원본 발화 단위 분할 격리
  • 화자와 원본 발화 ID 완전 분리
  • 세션 공통 이득 무작위화, 채널 간 차이는 ±0.5 dB 유지
  • 거리와 RTₐ₈ 직교 2×2 구성
  • 시작 시각 연속 오프셋, 채널 간 TDOA 보존
  • 평가셋 방위각·거리 bin 균등 층화
음량을 무작위화하면 소구경 배열의 거리 단서는 직접음 대 잔향음 비만 남습니다. 모델이 방의 잔향 시간을 거리로 착각하지 않는지 2×2 네 칸 모두에서 확인합니다.

05 / EVALUATION

Evaluation Setup

모든 시스템이 같은 평가셋과 같은 시간 격자, 같은 화자 매칭 규칙을 씁니다.

방위각은 36개 bin, 거리는 8개 bin으로 제출합니다. 채점 대상은 0.25초 격자 위의 정답 활성 발화 시점입니다.

단위가 다른 WER과 각도와 거리를 합산한 종합 점수는 쓰지 않습니다.

Azimuth bins값
bin 수36
간격10°
범위[−180, 180)
bin 중심−175 + 10i
Distance bins값
bin 수8
간격로그
범위0.5 – 5.0 m
bin 중심기하 평균

거리 bin을 로그 간격으로 둔 이유는 소구경 배열의 거리 단서가 직접음 대 잔향음 비이고, 그 비가 거리에 반비례하기 때문입니다. 등비 구간이 구간별로 비슷한 비 차이를 담습니다.

07 / LIMITS

Scope & Limits

결과를 미리 단정하지 않습니다. 한계도 결과에 포함합니다.

채널 수와 모호성

세 패널은 공유 y축(p 최대 0.70)과 같은 정답 bin을 씁니다. 구성 규칙을 캡션에 적었으므로 표시된 NLL은 그 입력에 채점 공식을 적용한 계산값입니다. 성능 숫자가 아닙니다.

마이크 1개로는 방향을 모릅니다

무지향 마이크 하나에는 방향 단서가 없습니다. 균일 분포가 정직한 출력이고, ACC@10°는 우연 수준이어야 맞습니다.

마이크 2개에는 대칭이 남습니다

두 마이크를 잇는 축 양쪽의 시간차가 같습니다. 양봉 분포를 그대로 제출하고, 대표점은 평균이 아니라 MAP bin 중심을 씁니다.

거리는 잔향에서 옵니다

음량을 무작위화하면 소구경 배열의 거리 단서는 직접음 대 잔향음 비만 남습니다. 방의 잔향 시간을 거리로 착각하는지 직교 2×2로 확인합니다.

관측이 길수록 좋다고 보지 않습니다

상태를 길게 누적하면 화자 전환 직후 이전 위치에 머무는 관성이 생깁니다. 시간 누적만으로 기하학적 대칭도 사라지지 않습니다.

데이터와 기여의 범위

eval-dev는 Image Source Method 시뮬레이션입니다. Unseen Room도 같은 시뮬레이터 안에 있어 일반화 검증으로는 약합니다. 실측 다채널 RIR 기반 분할을 별도 검증 조건으로 추가합니다.

새로운 위치 복원 원리를 제시하지 않습니다. 기여는 재현 가능한 과제 정의와 조건별 성능·한계 분석입니다.

중첩 발화는 이번 범위에서 제외했습니다. 중첩이 없는 조건에서 빔포밍의 WER 이득은 크지 않을 수 있고, 그 결과도 그대로 보고합니다.
